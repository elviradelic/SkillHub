# SkillHub – Workshop & Learning Platform

##  About the Project
SkillHub is a web-based learning platform designed to connect students and instructors through interactive courses, lessons, and assessments. The platform allows users to discover courses, enroll, access learning materials, and track their progress.

The goal of this project is to simulate a real-world e-learning system while applying software engineering principles, including system design, architecture, and development practices.

---

##  Features

### Release 1 – Core Platform
- User registration and authentication
- Role-based access (Student, Instructor, Admin)
- Course catalog and filtering
- Course details view
- Enrollment in courses
- Access to lessons and learning materials
- Course creation and management (Instructor)

### Release 2 – Advanced Features
- Quiz creation and completion
- Automatic grading system
- Progress tracking
- Certificate generation
- User reviews and ratings
- Admin management features
